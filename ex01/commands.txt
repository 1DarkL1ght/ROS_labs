===1
Название: wc
Описание: подсчет слов (строк) в файле
Синтаксис: wc [-l] [filename]
Пример: wc -l ex01 commands.txt 
===2
Название: sort
Описание: сортировка строк в файле
Синтаксис: sort [filename]
Пример: sort ex01/commands.txt
===3
Название: uniq
Описание: вывод уникальных элементов (например, строк в файле)
Синтаксис: uniq [filename]
Пример: uniq ex01/commands.txt
===4
Название: curl
Описание: прием и отправка данных с сервера или на сервер
Синтаксис: curl [url]
Пример: curl github.com/username/reponame
===5
Название: cowsay
Описание: корова говорит
Синтаксис: cowsay "text"
Пример: cowsay "Hello world"
===6
Название: diff
Описание: сравнение файлов построчно
Синтаксис: diff [file1] [file2]
Пример: diff main.py main1.py
===7
Название: history
Описание: История введенных команд 
Синтаксис: history
Пример: history 
===8
Название: find
Описание: поиск файла по имени, типу, дате, размеру 
Синтаксис: find [file]
Пример: find . -name "*.py"
===9
Название: ps
Описание: список текущих процессов
Синтаксис: ps [options]
Пример: ps
===10
Название: kill
Описание: убивает процесс
Синтаксис: kill [PID]
Пример: kill 4242
